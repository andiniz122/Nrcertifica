# Fotos dos cursos

Coloque aqui a foto de cada curso usando exatamente estes nomes:

| Curso      | Arquivo                  |
| ---------- | ------------------------ |
| NR-10      | `nr10.jpg`               |
| NR-10 SEP  | `nr10sep.jpg`            |
| NR-35      | `nr35.jpg`               |
| NR-12      | `nr12.jpg`               |
| NR-06      | `nr06.jpg`               |

Extensões aceitas: `.jpg`, `.jpeg`, `.png`, `.webp`.

Recomendação: recorte horizontal (proporção ~16:9 ou 3:2), no mínimo 800 px de
largura. O card mostra a faixa superior da imagem com um escurecimento por cima,
então o assunto principal deve ficar no centro do quadro.

Enquanto o arquivo não existir, o card usa o fundo em gradiente com o ícone do
curso — nada quebra por falta de imagem (ver `lib/imagens.ts`).
